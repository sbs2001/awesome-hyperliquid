- [HypurrFun](https://hypurr.fun/)
- [DeFi Trading Proxy](https://agent-gateway-kappa.vercel.app) - Hyperliquid perps trading proxy for AI agents. Part of Agent Gateway (34+ services). Bearer token auth, credit-based billing.
- [Hyperliquid Starter Bot](https://github.com/hypeprinter007-stack/hyperliquid-starter-bot) - Minimal, production-ready algo trading bot for Hyperliquid perps with fused signal layer (sentiment + macro + market structure).
- [deltafarm](https://github.com/Birantx/deltafarm) - Non-custodial delta-neutral funding farmer for Hyperliquid (long spot / short perp). Keys stay local, on-chain-verifiable builder fee, terminal dashboard, 166 tests.
- [Signalview](https://www.signalview.xyz/) - Non-custodial AI agents that trade backtested, scored perps signals 24/7 using Hyperliquid agent keys (orders only, never withdrawals). Free to run.
- [Testudo](https://github.com/sub0xdai/testudo) - Open-source crypto exchange platform with Rust matching engine, Hyperliquid agent wallet integration, shadow-mode paper trading, and multi-exchange support.
- [HyperGrok Trading Desk](https://github.com/galleonlabs/hypergrok-trading-desk) - Grok-first Hyperliquid desk: seven roles and seventeen shared skills for setup, market data, risk, ticketed execution, and review. `npx skills add galleonlabs/hypergrok-trading-desk`
- [TV-Hub](https://www.tv-hub.org/) - Executes TradingView alerts and forwarded Telegram signals as Hyperliquid orders, plus DCA and grid bots. Free when you approve the TV-Hub builder fee.
- [CopyHype](https://copyhype.family/) - Telegram Mini App and bot to copy active Hyperliquid traders in one tap, ranked by 7-day ROI, or trade solo on crypto, stocks, gold, indices and meme perps. Non-custodial wallet, from $2 a trade, free 7-day practice with $1,000 of play money.

### Analytics

- [Dune](https://dune.com/mogie/hyperliquid-flows)
- [DefiLlama](https://defillama.com/chain/Hyperliquid)
- [HyperAlerts](https://hyperliquid.tv/) - Free real-time Hyperliquid alerts and analytics for prices, funding, open interest, volume, wallets, large trades, news, HIP-3 earnings, and market hours.
- [OpenChainBench](https://openchainbench.com/hyperliquid) - Open live benchmarks of Hyperliquid infrastructure: builder revenue across 104 frontends, HIP-3 deployer fees, perp costs. Public Prometheus, data CC-BY-4.0
- [perp.wiki](https://perp.wiki) - Hyperliquid ecosystem directory and live market data: funding rates, OI, volume, token listings, and protocol comparisons
- [OpenChainBench](https://openchainbench.com/benchmarks/hyperliquid-frontends) - Live builder revenue leaderboard for all Hyperliquid frontends (104+ tracked) and HIP-3 deployers. Onchain-verified, open methodology, CC BY 4.0 data. JSON API + MCP server.
- [VaultVision](https://vaultvision.tech/vaults/scanner) - Hyperliquid vault scanner with live risk-adjusted rankings, TVL, max drawdown, deposit status, entry quality, alerts, and crawlable vault detail pages.
- [CryptoAnimon](https://cryptoanimon.com/en/?src=awesome) - Any Hyperliquid wallet's rounds marked to market, live liquidation maps, a free Daily, and Telegram alerts when a wallet trades.
- [Hyperliquid Discipline Report](https://tradecopilot.app/hyperliquid-discipline-report) - Free behavioural report for any wallet, built from its public perp fills: revenge trading, tilt speed, sizing up after losses, letting losers run, overtrading and fee drag, all net of fees.


- [WatchCrypto](https://watchcrypto.io/exchanges/hyperliquid) - Free chart-first trading terminal for every Hyperliquid perp: 1-second candles, full order book and trade tape, TP/SL on the chart, and a live funding-rate table for all perps.

- [Yieldo Funding Benchmark](https://yieldo.me/blog/funding/funding-rate-benchmark-hyperliquid-vs-cex) - Open dataset comparing annualised perpetual funding on Hyperliquid against other perp DEXes and a median of 9 centralised exchanges. Daily panel of 31,342 rows over 12 venues and 62 coins since 2026-07-05, with the funding interval and observation counts published per row. Live JSON/CSV feeds, versioned snapshots archived under DOI 10.5281/zenodo.22556012, CC BY 4.0.

- [TraderSpy](https://traderspy.app/) - Smart-money tracker for top Hyperliquid traders' positions and PnL (alongside Binance, Bybit and OKX), plus Hyperliquid charts with a live order book and paper trading.

- [PerpLedger](https://swarm-t3.github.io/perpledger/) - Yearly realized PnL, fees and funding for any address, plus a Koinly-ready tax CSV (perps, funding, spot, transfers). Runs in the browser on the public API.

- [TrueHold](https://www.truehold.xyz/track/hyperliquid) - Portfolio tracker that reads Hyperliquid positions and P&L by wallet address, next to other wallets and exchange accounts.

- [perpbook](https://perpbook.vercel.app/) - Open-source trading journal and PnL tracker: paste an address to rebuild every perp trade from its fills, with PnL after fees and funding checked against Hyperliquid's own figure ([GitHub](https://github.com/patrickballard/perpbook)).

- [Hyperliquid builder fees report](https://floatout.xyz/hyperliquid-builder-revenue) - Daily gross USDC builder fees split by perps, HIP-3, HIP-4 and spot, with daily builder address counts, scanned from node fill data. CSV and JSON downloads, per-day source hashes, CC BY 4.0.

### APIs & Tools

-[hyper-evm-lib](https://github.com/hyperliquid-dev/hyper-evm-lib) - most widely adopted library for smart contracts on Hyperliquid.


- [Bitquery Hyperliquid API](https://docs.bitquery.io/docs/perpetuals/hyperliquid) - GraphQL and WebSocket API for Hyperliquid core, serving the book at **L3 (market-by-order)**: every order delta carries its own order id and the wallet address that placed it, market-wide and at unlimited depth. Also covers trades, OHLCV candles, liquidations, funding, positions, leverage, TWAPs, mark prices and signed actions. The same query runs as a historical query or a real-time subscription.

- [Hyperliquid REST API Wrapper](https://hyperliquid-api-deploy.vercel.app) — Free REST API wrapper for Hyperliquid market data. Simple GET endpoints for 275+ perp prices, L2 orderbooks, OHLCV candles, funding rates, and account data. No API key needed for free tier (100 req/day). Docs + live demo at the link.
- [HyperEVM eth_getLogs backfill](https://github.com/blockvectra/hyperevm-getlogs-backfill) - Runnable Node script that splits HyperEVM `eth_getLogs` backfills into chunks sized to the RPC's block-range limit, with a 30-day call-count model.

- [Hydromancer](https://hydromancer.xyz/) - Hyperliquid data API: REST and WebSocket access to fills, positions for up to 1,000 wallets per request, liquidations and L2/L4 order book streams, plus Reservoir, a free historical data archive on AWS S3.
- [Resolved Markets](https://resolvedmarkets.com) - Historical and live Hyperliquid perp order books alongside Polymarket order book data, via REST, WebSocket and MCP. Hyperliquid data requires a paid plan.
- [Vextorium](https://vextorium.com) - Pay-per-call Hyperliquid data for bots and AI agents: liquidation map of large accounts, whale positions, funding history, basis, vaults and markets, paid per call in USDC via x402 (no API key). Open-source Python client with a freqtrade helper: [vextorium-python](https://github.com/bru1noia/vextorium-python).

- [hl-builder-fees](https://github.com/Floatout/hl-builder-fees) - Zero-dependency TypeScript library for builder code fee math: `f` unit conversions, per-product caps (perps, spot, HIP-3, HIP-4), asset id classification, exact BigInt fee and split calculations. MIT, on npm.
